Кнопка прогоняет размеченные проходы через стоящую модель и пересчитывает эталон каждого кота. Сеть при этом не обучается: новый кот получает эталон по десятку размеченных проходов, и макбук для этого не нужен вовсе.

Новые эталоны применяются, только если они не пускают больше чужих, чем прежние. Если стало хуже — остаются старые, и здесь будет сказано почему. Чего пересчёт не умеет: улучшить само зрение. Если модель не различает двух чёрных котов в темноте, среднее этого не исправит — это работа для обучения на макбуке.
