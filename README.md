# CatDoor AI

Локальная система визуальной идентификации домашних кошек и управления автоматической дверцей.

## Основная схема

- две IP-камеры: морда и боковой вид;
- Windows-моноблок Intel Core i3-8109U, 16 ГБ RAM, SSD 512 ГБ;
- MacBook M5 для обучения моделей;
- ONNX/OpenVINO для инференса на Windows;
- локальная веб-админка;
- ESP32/Arduino для безопасного управления механикой;
- без RFID и без облачного инференса.

Полный контекст проекта находится в [PROJECT_BRIEF.md](PROJECT_BRIEF.md).

## Первый milestone

Первая версия не использует нейросеть и не управляет реальной дверью. Она должна:

1. Подключаться к двум RTSP-камерам.
2. Показывать их состояние.
3. Сохранять синхронные тестовые события.
4. Вести SQLite-базу.
5. Показывать журнал событий через браузер.
6. Позволять вручную назначать событию кота.
7. Экспортировать размеченные события в ZIP.
8. Работать как служба Windows.
9. Восстанавливаться после разрыва RTSP.

## Статус

Проект находится на стадии проектирования и создания первого прототипа.

## Локальная админка MVP

В ветке разработки доступен небольшой интерфейс для первой камеры:

- живое превью RTSP через локальный FFmpeg;
- сохранение короткого события в MP4;
- журнал последних событий;
- ручная разметка события как домашней кошки, чужой кошки, случая без видимой
  кошки или случая с несколькими кошками.
- удаление отдельного ошибочного прохода вместе с его видео после подтверждения.
- назначение размеченных проходов для MacBook или локального эксперимента;
- скачивание подготовленного ZIP для MacBook и запуск короткого локального
  обучения отдельным процессом.

Все действия локальные. Управление дверью отсутствует.

Локальное обучение использует CPU и предназначено для проверки pipeline, а не
для замены основного обучения на MacBook M5. Число экспериментальных эпох
задаётся через `CATDOOR_LOCAL_TRAINING_EPOCHS` (по умолчанию `2`).

### Запуск

1. Активируйте виртуальное окружение:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

2. Создайте локальный `.env` (он исключён из Git) и укажите как минимум:

   ```dotenv
   CATDOOR_CAMERA_FACE_RTSP=rtsp://USER:PASSWORD@CAMERA_IP:554/media/video1
   CATDOOR_DATA_DIR=C:\CatDoorData
   CATDOOR_FFMPEG_PATH=ffmpeg
   ```

3. Запустите:

   ```powershell
   python -m src.web.app
   ```

4. Откройте `http://127.0.0.1:8080`.

Пароль камеры и полный RTSP URL нельзя добавлять в Git, документацию или логи.
На текущем MVP кнопка начинает запись с момента нажатия. Кольцевой буфер с
предысторией будет реализован в отдельном recorder-процессе.

## Обучение и приёмка модели

В `training/` находится локальный конвейер подготовки манифеста, разделения
датасета по событиям, обучения MobileNetV3 на MacBook/MPS, экспорта ONNX,
формирования пакета с SHA-256 и независимой приёмки на Windows через ONNX Runtime.
Подробности: `docs/model-training-and-acceptance.md`.
