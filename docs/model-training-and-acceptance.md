# Обучение и приёмка модели

## Граница доверия

MacBook формирует пакет модели, но не определяет окончательно, пригоден ли он для
целевой машины. Windows-моноблок повторно проверяет SHA-256 и выполняет инференс
на отдельном локальном наборе. Отчёт приёмки не активирует модель автоматически.

```text
размеченные события
       ↓
manifest.jsonl → проверка утечек событий → train/validation/test
       ↓
PyTorch/MPS на Mac → checkpoint → ONNX
       ↓
model_info + thresholds + SHA-256 → ZIP
       ↓
офлайн-перенос
       ↓
проверка ZIP → ONNX Runtime CPU → FAR/FRR/latency report
```

## Контракты

### Датасет

Обязательные поля строки JSONL:

- `event_id`;
- `captured_at` в ISO 8601;
- `view`: `face` или `side`;
- относительный `image_path`;
- `label`, где `__foreign__` обозначает чужую кошку;
- `split`: `train`, `validation`, `test` или `null`.

Разбиение выполняется по `event_id`, поэтому соседние кадры одного прохода не
могут оказаться в разных частях.

Каждый `image_path` указывает на кроп самой уверенной рамки кошки, расширенный
на 20% с каждой стороны. Подготовка набора выполняет локальный детектор на
Windows; кадры без рамки выше порога камеры не включаются и подсчитываются в
`dataset-report.json`.

### Пакет

Минимальный пакет содержит:

- один или несколько файлов `*.onnx`;
- `model_info.json`;
- `thresholds.json`;
- `checksums.sha256`.

ZIP разрешает только файлы верхнего уровня. Абсолютные пути и `..` отклоняются.
Пакет собирается без повторного сжатия ONNX, чтобы уменьшить лишнюю нагрузку.

### Приёмочный отчёт

Отчёт содержит:

- число домашних и чужих примеров;
- accuracy;
- False Accept Rate;
- False Reject Rate;
- долю `uncertain`;
- среднее время инференса;
- результат проверки лимита средней задержки на целевой машине;
- итог `passed`;
- неизменяемое поле `activated: false`.

Отсутствие домашних или чужих примеров всегда означает провал приёмки.
Превышение `max_mean_inference_ms` также означает провал.

## Текущие ограничения

- инфраструктура обучает простой closed-set MobileNetV3-классификатор;
- `__foreign__` применяется при калибровке/приёмке, но не как обучаемый класс;
- отдельный выбор лучших кадров, детектор именно морды/тела, embeddings и fusion
  появятся отдельными изменениями;
- пороги из примера не являются производственными;
- OpenVINO benchmark и сравнение с ONNX Runtime ещё не автоматизированы.
