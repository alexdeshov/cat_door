# Архитектура

Подробный исходный контекст находится в `PROJECT_BRIEF.md`.

## Компоненты

- `CatDoorRecorder` — RTSP, буферы и запись событий.
- `CatDoorInference` — детекция и идентификация.
- `CatDoorController` — связь с ESP32/Arduino.
- `CatDoorWeb` — локальная веб-админка и API.
- `CatDoorWatchdog` — мониторинг служб, камер, диска и контроллера.

## Принцип отказоустойчивости

Каждый компонент должен иметь ограниченную ответственность. Падение веб-интерфейса не должно останавливать запись, а сбой модели не должен приводить к небезопасному действию двери.
