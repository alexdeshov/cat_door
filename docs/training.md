# Обучение моделей

## Среда

Обучение выполняется на MacBook M5 через PyTorch/MPS. С 2026-08-11 рабочая
схема опознания — **эмбеддинги** (`training/train_embeddings.py`): сеть учится
пространству, эталон кота — среднее его векторов, «чужой» получается порогом.
Классификатор (`training/train_classifier.py`) остаётся запасной веткой.

Пополнение памяти обученного пространства макбука не требует: кнопка
«Запомнить заново» в админке пересчитывает эталоны прямо на узле.

## Перенос

Финальные модели экспортируются в ONNX и запускаются на узле (Ubuntu) через OpenVINO.

## Данные

Первая цель на каждого кота:

- минимум 100 независимых событий;
- около 500 кадров морды;
- около 500 кадров сбоку.

Кадры одного события не должны одновременно попадать в train, validation и test.

Реализованный конвейер, формат JSONL, команды экспорта ONNX и приёмки описаны
в `docs/model-training-and-acceptance.md` и `training/README.md`. Весь путь от
разметки до пакета модели выполняется одной командой:
`python -m scripts.identity_pipeline all` (см. `docs/identity-training.md`).

## Экспериментальное локальное обучение

Короткий локальный запуск разрешён для проверки полного pipeline. Он использует
тот же MobileNetV3 и формат манифеста, но работает на CPU, с размером изображения
160 и небольшим числом эпох. Его результат нельзя принимать как готовую модель
без полного обучения, ONNX-экспорта и независимой приёмки.

События для MacBook и локального запуска выбираются в админке. Набор `macbook`
сначала собирается отдельным фоновым процессом (кнопка «Собрать набор для
MacBook», это около часа), затем скачивается готовым ZIP; выборка `local`
обрабатывается так же фоном. Для локального запуска установите зависимости:

```sh
.venv/bin/pip install -e ".[training]"
```

Локальное обучение требует как минимум двух подтверждённых домашних котов,
непустых train и validation split и пригодных кадров выбранного ракурса.
Для fine-tuning также требуются официальные ImageNet-веса MobileNetV3 Small:
они берутся из cache torchvision или из пути
`CATDOOR_IDENTITY_PRETRAINED_WEIGHTS_PATH`. Веса хранятся вне Git.
