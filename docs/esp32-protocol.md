# Протокол ESP32 (историческая справка)

**Не реализуется.** Силовую механику коммутирует плата реле Waveshare Modbus
PoE ETH Relay (B): она уже стоит, разговаривает по Modbus TCP через шлюз и
разделяет контуры сухими контактами. Отдельный ESP32/Arduino не заводится —
см. `AGENTS.md`.

Требования ниже сохранены как список свойств, которых мы добивались и добились
другими средствами:

- heartbeat — файл-отметка службы калитки (`heartbeat_path`);
- тестовая команда — кнопки «Открыть калитку» и «Открыть дверцу» в админке;
- подтверждение выполнения — эхо Modbus разбирается и пишется в журнал;
- тайм-аут и повтор — `RelayOpener` (одна попытка повтора при молчании платы);
- безопасное состояние — команда «мигнуть» сама размыкает контакт: смерть
  процесса не оставляет ни калитку разомкнутой, ни защёлку под током.
