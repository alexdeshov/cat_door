# История рабочих сессий

Этот журнал хранит краткий контекст завершённых рабочих сессий Codex. Он помогает
продолжать работу без восстановления решений только по истории чата.

## Правила ведения

- Новые записи добавляются в конец файла.
- Одна рабочая сессия создаёт не более одной итоговой записи.
- Запись должна быть короткой и содержать только проверяемые факты.
- Незавершённая работа и блокирующие проблемы отмечаются явно.
- Секреты, RTSP URL, IP-адреса камер, учётные данные, токены, персональные данные
  и сведения из реальных видео не записываются.
- Подробные архитектурные описания остаются в профильных документах; здесь
  сохраняются только итог и ссылки на них.

## Шаблон

```md
## YYYY-MM-DD — Краткое название

- Цель: что требовалось получить.
- Сделано: какой результат создан.
- Решения: какие существенные решения приняты.
- Изменённые файлы: перечень основных файлов.
- Проверки: какие проверки выполнены и их результат.
- Статус: завершено, частично завершено или заблокировано.
- Следующий шаг: ближайшее логичное продолжение.
```
