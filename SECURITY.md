# Security Policy

## Секреты

Запрещено коммитить:

- `.env`;
- пароли камер;
- RTSP URL с логином и паролем;
- GitHub tokens;
- Telegram tokens;
- пароли веб-админки;
- приватные ключи;
- реальные видео и полный датасет.

Используйте `.env.example` только как шаблон.

## Сеть камер

Камеры должны работать в отдельной локальной подсети без шлюза и DNS, если доступ в интернет не требуется.

## Физическая безопасность

Windows-приложение не управляет приводом напрямую. Контроллер ESP32/Arduino обязан самостоятельно:

- учитывать концевики и датчики прохода;
- останавливать привод по тайм-ауту;
- переходить в безопасное состояние при потере связи;
- иметь ручную механическую разблокировку.

До отдельного разрешения допускается только симуляция действия двери.
