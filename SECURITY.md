# Security Policy

## Секреты

Запрещено коммитить:

- `.env`;
- пароли камер;
- RTSP URL с логином и паролем;
- GitHub tokens;
- Telegram tokens;
- пароли веб-админки;
- приватные ключи;
- реальные видео и полный датасет.

Используйте `.env.example` только как шаблон.

## Сеть камер

Камеры должны работать в отдельной локальной подсети без шлюза и DNS, если доступ в интернет не требуется.

## Физическая безопасность

Силовую механику коммутирует плата реле Waveshare (Modbus TCP) в границах
письменных разрешений владельца из `AGENTS.md`. Свойства, которых требует это
правило:

- команда «мигнуть» сама размыкает контакт: смерть процесса, обрыв сети или
  перезагрузка не оставляют калитку разомкнутой, а защёлку — под током;
- эхо платы проверяется; молчание даёт одну повторную попытку, отказ платы —
  нет;
- на плату пишет единственная служба, остальные просят открытия одноразовым
  файлом-просьбой с защитой от повтора после перезагрузки (boot_id + срок
  годности);
- каждое срабатывание попадает в журнал и в Телеграм;
- замком калитки распоряжается контроллер Novicam SX120KW — система лишь
  замыкает его «кнопку выхода», в цепь замка не вмешивается;
- автоматика включается только владельцем, умолчание всегда `off`.
